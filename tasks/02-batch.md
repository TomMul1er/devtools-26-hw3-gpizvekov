# Часть 2. Обработать каталог файлов • 1,5 балла

Коллеги прислали [три CSV](../samples/batch). В одном ошибка, но по двум остальным нужны отчёты. Давайте допишем `scripts/batch.sh`, чтобы он обработал весь каталог, сохранил отчёты и записал ошибку в лог. (Сервер тут трогать не будем)

## 2.1. Обработать каталог • 0,75 балла

**Требования:**

- Скрипт передаёт готовому анализатору `app/analyzer.py` каждый обычный файл `.csv` из входного каталога. Подкаталоги и символические ссылки пропускаются.
- В имени отчёта замените расширение `.csv` на `.json`, в имени лога – на `.log`. В лог записывается stderr анализатора.
- Повреждённый файл не останавливает обработку остальных.

Запустите скрипт на готовых примерах. Передайте по порядку каталог с CSV, каталог отчётов и каталог логов. Два последних скрипт создаёт при необходимости.

```bash
bash scripts/batch.sh samples/batch work/batch-reports work/batch-logs
```

Сверьте результат с таблицей.

| Входной каталог | Каталог отчётов | Каталог логов |
|---|---|---|
| `run_01.csv` | `run_01.json` | `run_01.log`, пустой |
| `missing_values.csv` | `missing_values.json` | `missing_values.log`, пустой |
| `broken.csv` | отчёта нет | `broken.log` с ошибкой |

В `missing_values.csv` пустые метрики допустимы. В `broken.csv` вместо числа в столбце `accuracy` стоит `not-a-number`.

## 2.2. Ошибки, повторный запуск и логи • 0,75 балла

В отдельной оболочке Bash запустите анализатор на `samples/batch/broken.csv`. Повторите запуск, передав stderr анализатора через `tee` в лог. Совпал ли код завершения конвейера с кодом самого анализатора?

Скопируйте `samples/clean.csv` в отдельный входной каталог и обработайте этот каталог с помощью `batch.sh`. Замените рабочую копию файлом `samples/batch/broken.csv` под тем же именем `clean.csv`. Повторите команду с теми же каталогами. Что теперь в `clean.log`? Что должно произойти с прежним `clean.json`?

**Требования:**

- Скрипт перезаписывает лог каждого обработанного файла. При успехе заменяет отчёт, при ошибке удаляет прежний. Остальные файлы в каталогах результатов сохраняются.
- Если используется конвейер, ошибка анализатора должна попасть в итоговый счётчик ошибок.
- Последняя строка stdout содержит число успешных обработок и ошибок в формате `processed=N failed=M`. Для `samples/batch` получится `processed=2 failed=1`.

| Код завершения | Когда |
|---|---|
| `0` | Все найденные CSV обработаны успешно. |
| `1` | Хотя бы один CSV обработан с ошибкой. |
| `2` | Указаны неверные аргументы, входного каталога нет, в нём нет подходящих CSV или не удалось подготовить каталоги результатов. Причина выводится в stderr. Строка счётчиков не нужна. |

В проверках каталоги входных файлов, отчётов и логов различаются. Имена могут содержать пробелы и кириллицу. Скрытых CSV, переносов строк в именах и имён с начальным `-` не будет.

**Самопроверка.** Проверьте повторный запуск на временной копии CSV:

```bash
python tools/self-check.py batch
```
